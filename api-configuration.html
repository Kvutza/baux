baux.OptimizerConfig

Source

The complete optimizer configuration.

baux.OptimizerConfig(
    trust_region: TrustRegionConfig = TurboTrustRegion(),
    candidates: CandidateConfig = CandidateConfig(),
    init: InitConfig = InitConfig(),
    surrogate: Surrogate = NoSurrogate(),
    acquisition: AcquisitionConfig = RandomAcquisitionConfig(),
    acq_optimizer: AcqOptimizerConfig = ...,
    observation_history: ObservationHistoryConfig = ObservationHistoryConfig(),
)

Frozen dataclass. Fields: trust_region, candidates, init, surrogate, acquisition, acq_optimizer and observation_history. Use dataclasses.replace to change fields.

The default is a single TuRBO region, no surrogate and random acquisition. The pipeline helpers construct compatible combinations.

Surrogate choices include ENNSurrogate, GaussianProcess, ExternalSurrogate and NoSurrogate. Region choices include TurboTrustRegion, MorboTrustRegion, RegionalSearchPolicy and NoTrustRegion. Configuration records are in baux.turbo.config; commonly used types are also exported by baux.

baux.RegionalSearchPolicy

Source

Configure region sharing, allocation and restart behavior.

baux.RegionalSearchPolicy(
    count: int = 4,
    length: TrustRegionBounds = TrustRegionBounds(),
    success_tolerance: int = 3,
    failure_tolerance: int = 5,
    sharing: Literal["box_contain", "ellipsoid_ball", "nearest_center", "origin_only"] = "box_contain",
    allocation: Literal["incumbent_ucb1", "least_trials", "joint_acquisition"] = "incumbent_ucb1",
    restart_memory: Literal["fresh", "retain_relevant"] = "fresh",
    restart_center: RestartCenterPolicy = RestartCenterPolicy(),
    controller: Literal["turbo", "fixed_radius"] = "turbo",
    acquisitions: tuple[AcquisitionConfig | None, ...] = (),
)

count, success_tolerance and failure_tolerance must be positive. length supplies normalized trust-region bounds.

sharing: "box_contain", "ellipsoid_ball", "nearest_center" or "origin_only". This constructor defaults to "box_contain"; the regions() helper defaults to "ellipsoid_ball".

allocation: "incumbent_ucb1", "least_trials" or "joint_acquisition". controller: "turbo" or "fixed_radius".

restart_memory: "fresh" or "retain_relevant". restart_center: a RestartCenterPolicy from baux.turbo.config.candidates.

acquisitions: empty to inherit the optimizer's rule, or a tuple with one acquisition configuration (or None to inherit) per region. Supported records are UCBAcquisitionConfig, DrawAcquisitionConfig, ParetoAcquisitionConfig and RandomAcquisitionConfig from baux.turbo.config.acquisition.

baux.TrustRegionBounds

Source

Initial, minimum and maximum region lengths.

baux.TrustRegionBounds(length_init=0.8, length_min=0.0078125, length_max=1.6)

Requires 0 < length_min <= length_init <= length_max. Lengths are measured in normalized coordinates. Pass to a region policy or use tr_bounds in a pipeline.

baux.turbo_enn

Source

Create an ENN optimizer configuration preset.

baux.turbo_enn(
    *,
    enn=None,
    trust_region=None,
    candidates=None,
    num_init=None,
    acquisition=AcquisitionKind.PARETO,
)

Returns OptimizerConfig. Defaults to Pareto acquisition. Accepts explicit ENN, region and candidate configurations and an initialization budget.

The default acquisition differs from baux.enn(), which normally selects UCB. Use an explicit acquisition when comparing configurations.

baux.turbo_one

Source

Create a Gaussian-process TuRBO configuration.

baux.turbo_one(
    *,
    num_candidates=None,
    num_init=None,
    trust_region=None,
    sampler=CandidateSampler.SOBOL,
    acquisition=AcquisitionKind.THOMPSON,
)

Returns OptimizerConfig. Defaults to Sobol candidates and Thompson acquisition. Optional arguments override candidate count, initialization budget, region policy, sampler and acquisition.

baux.turbo_zero

Source

Create a surrogate-free trust-region configuration.

baux.turbo_zero(
    *,
    num_candidates=None,
    num_candidates_per_arm=None,
    num_init=None,
    trust_region=None,
    sampler=CandidateSampler.SOBOL,
)

Returns OptimizerConfig with random selection. Defaults to Sobol candidates. Candidate budgets, initialization budget and region policy can be supplied explicitly.

baux.lhd_only

Source

Create a Latin-hypercube exploration configuration.

baux.lhd_only(
    *,
    num_candidates=None,
    num_init=None,
    trust_region=None,
    sampler=CandidateSampler.SOBOL,
)

Returns OptimizerConfig without a surrogate. Sets LHD-only initialization. Accepts candidate and initialization budgets plus sampler and region arguments for the preset constructor.
