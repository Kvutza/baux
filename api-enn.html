baux.enn_init

Source

Create an ENN dataset and neighbor index.

baux.enn_init(
    train_x,
    train_y,
    train_yvar=None,
    *,
    scale_x=False,
    stiefel=None,
    affine=None,
    **options,
)

train_x: (N, D) inputs. train_y: (N,) or (N, M) outputs. train_yvar: optional matching observation variances. Returns ENNState.

scale_x enables input scaling; stiefel and affine supply output maps. Additional options are forwarded to ENN, including index_driver, device, index, storage, work_dir and y_bounds.

This creates the dataset; enn_fit returns parameters used to query it.

Example 
import numpy as np
import baux

x = np.array([[0.0], [1.0], [2.0], [3.0], [4.0]])
y = np.sin(x)
state = baux.enn_init(x, y)
params = baux.enn_fit(state, k=3, num_samples=5, seed=0)
q = np.array([[0.5], [1.5], [2.5]])
post = baux.enn_posterior(state, q, params)
draws, idx = baux.enn_sample(state, q, params, num_draws=4)
x_new = np.full((1, 1), 5.0)
state2 = baux.enn_append(state, x_new, np.sin(x_new))

assert post.mu.shape == (3, 1)
assert draws.shape == (3, 1, 4)
assert len(state2) == 6

baux.enn_append

Source

Append observations to an ENN state.

baux.enn_append(state, x, y, y_var=None)

x: (N, D) inputs. y: (N,) or (N, M) outputs. Returns a new ENNState, leaving the input state unchanged.

The presence of y_var must match the existing dataset: either both old and new observations have variances, or neither does. Alias: baux.append.

baux.enn_fit

Source

Fit ENN variance scales for a neighbor count.

baux.enn_fit(
    state,
    k=10,
    *,
    num_candidates=100,
    num_samples=10,
    infer_aleatoric=True,
    key=None,
    seed=None,
    warm=None,
)

Returns ENNParams; the dataset is unchanged. k: number of neighbors. num_candidates: parameter-search budget. num_samples: leave-one-out sample budget.

infer_aleatoric controls fitting the aleatoric scale. warm supplies previous parameters. key takes precedence over seed. Alias: baux.fit.

baux.enn_posterior

Source

Predict means and uncertainty at query points.

baux.enn_posterior(state, x, params, *, flags=None)

x: (Q, D) query array. params: fitted ENNParams. Returns ENNNormal with mu, se, se_epi and se_ale arrays of shape (Q, M).

flags is a PosteriorFlags from baux.enn.posterior_flags. Its defaults are exclude_nearest=False, observation_noise=False, tie_neighbors=True. Set observation_noise=True to include observation noise in reported uncertainty. Alias: baux.posterior.

baux.enn_sample

Source

Draw functions from the ENN prediction model.

baux.enn_sample(state, x, params, *, key=None, num_draws=1, seeds=None, flags=None)

x: (Q, D) queries. Returns (draws, neighbor_ids); draws has shape (Q, M, S).

num_draws sets S when seeds are generated from key. Explicit seeds overrides that generation and determines the draw count. Reusing function seeds couples queries through shared observation-level randomness.

flags has the same meaning as in enn_posterior; observation noise is excluded by default. Alias: baux.sample.

baux.ENNState

Source

A dataset and index for functional ENN queries.

class baux.ENNState  (frozen dataclass; constructed via baux.enn_init)

Construct it with enn_init, then use enn_append to add data. x, y and optional y_var are read-only arrays; len(state), num_dim and num_outputs describe their dimensions.

key is derived from the stored data and options. Fitted parameters are returned separately by enn_fit.

baux.ENNParams

Source

Parameters required for an ENN prediction.

baux.ENNParams(k_neighbors, epistemic_scale, aleatoric_scale)

k_neighbors: neighbor count. epistemic_scale and aleatoric_scale: variance multipliers. Usually returned by enn_fit or ENNFitter.ask.

baux.Posterior

Source

A native posterior result for device queries.

class baux.Posterior  (device-resident posterior; paired with host baux.enn.ENNNormal)

Exposes mean, se and draw(seeds) through native buffers. This differs from the NumPy ENNNormal returned by enn_posterior. Check backend operation support with capabilities.

baux.NeighborIndex

Source

Select a nearest-neighbor backend.

class baux.NeighborIndex(enum.Enum)

Members: FLAT, AUTO, USEARCH, BPANN_DISK, METAL, OPENCL, CUDA. Supply a member as index_driver to ENN. Availability depends on the native build and hardware.

baux.DistanceMetric

Source

Select the index distance.

class baux.DistanceMetric(enum.Enum)

Members: SQUARED_L2 and COSINE. The native optimizer's ENN configuration requires SQUARED_L2. This enum is separate from the geometry names accepted by with_geometry.
