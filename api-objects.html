Resident objects

Resident objects encapsulate acceleration buffers, Metal search state, and multi-region portfolios. The functional interface (such as baux.init, baux.ask, and baux.tell) manipulates immutable OptimizerState values; these resident objects provide direct handle semantics for high-throughput GPU workflows and native buffers.

baux.Telemetry

baux.Telemetry(
    dt_fit: float,
    dt_sel: float,
    dt_gen: float = 0.0,
    dt_tell: float = 0.0,
    num_candidates: int = 0,
)

Timings and candidate count from optimizer work.

dt_fit, dt_sel, dt_gen and dt_tell are durations in seconds. num_candidates is the candidate count. Available on optimizer state as state.telemetry.

Example

import numpy as np
import baux

bounds = np.array([[-1.0, 1.0], [-2.0, 2.0]])
st = baux.init(bounds, seed=0)
st, batch = baux.ask(st, 2)
st, _ = baux.tell(st, batch, np.sum(batch.points**2, axis=-1, keepdims=True))
telem = st.telemetry

assert isinstance(telem, baux.Telemetry)
assert telem.num_candidates >= 0
print("telemetry:", telem.dt_fit, telem.dt_sel, telem.num_candidates)

baux.Region

class baux.Region

Apple Metal resident trust region search state.

Maintains trust region centers, local step sizing, success/failure counters, and on-device proposal generation for Apple Silicon acceleration. Call region.ask(...) to obtain (next_region, trial), and region.tell(trial, y) to record objective values and return (next_region, y_best).

Source in rust/crates/baux-py/src/py_metal.rs

baux.Trial

class baux.Trial

Apple Metal resident proposal ticket.

Encapsulates candidate weights and coordinate evaluation tickets generated by a resident Region. Provides trial.weights() or trial.var() to access resident parameter buffers without host transfers.

Source in rust/crates/baux-py/src/py_metal/py_buf.rs

baux.Portfolio

class baux.Portfolio

Apple Metal multi-region portfolio search coordinator.

Coordinates multiple trust regions across diverse search spaces with resident allocation strategies and cross-region sharing. Call portfolio.ask(...) to obtain (next_portfolio, trials) as RegionTrial tickets, and portfolio.tell(trials, y) to return (next_portfolio, imported).

Source in rust/crates/baux-py/src/py_portfolio.rs

baux.RegionTrial

class baux.RegionTrial

Apple Metal multi-region proposal ticket.

Encapsulates candidate evaluation proposals returned from a Portfolio. Exposes ticket.region, ticket.generation, and ticket.weights() for evaluating points across regions.

Source in rust/crates/baux-py/src/py_portfolio.rs

baux.Tensor

class baux.Tensor

Device-resident multi-backend buffer with DLPack export.

Represents contiguous multi-dimensional arrays resident on accelerator backends (CPU, Metal, CUDA). Supports zero-copy DLPack protocol export via __dlpack__() and __dlpack_device__() to PyTorch, JAX, or NumPy.

Source in rust/crates/baux-py/src/py_posterior.rs

baux.Var

class baux.Var

Apple Metal resident parameter weights buffer.

Encapsulates 16-bit float weight representations stored in Metal device memory, enabling parameter evaluation and kernel operations without CPU memory round-trips.
