These objects update in place. In particular, optimizer.ask(N) returns points directly and optimizer.tell(x, y) returns fitted means. The functional interface returns a new state alongside its result.

baux.create_optimizer

Source

Create an optimizer that updates in place.

baux.create_optimizer(*, bounds, config, rng)

All arguments are keyword-only. bounds: (D, 2) array. config: an OptimizerConfig. rng: a NumPy random generator. Returns Optimizer.

Use baux.chain(...) to compile transforms before passing them as config. For structured parameters and explicit state transitions, use baux.init.

Example 
import numpy as np
import baux

bounds = np.array([[-1.0, 1.0], [-2.0, 2.0]])
cfg = (baux.enn(k=5) | baux.ucb(beta=1.5))()
rng = np.random.default_rng(0)
opt = baux.create_optimizer(bounds=bounds, config=cfg, rng=rng)
x = opt.ask(num_arms=3)
y = np.sum(x**2, axis=-1, keepdims=True)
pred = opt.tell(x, y)
telem = opt.telemetry()

assert x.shape == (3, 2)
assert pred.shape == (3, 1)
assert isinstance(telem, baux.Telemetry)

baux.Optimizer

Source

An in-place ask/tell optimizer.

class baux.Optimizer  (constructed via baux.create_optimizer)

Construct with create_optimizer. ask(N) returns a coordinate matrix; ask_batch(N) returns an AskBatch with typed regional tickets.

tell(x, y, y_var=None) records a batch and returns fitted means. complete(ids, y, y_var=None) and cancel(ids) update regional tickets in place and return None. restart_region(slot, center) returns abandoned tickets.

import_observations(x, y, y_var=None) adds external data. posterior_mu(x) predicts without ingestion. Properties include num_observations, num_regions, tr_length, init_progress and pending_ids. telemetry() returns phase timings.

baux.ENN

Source

A mutable ENN dataset and prediction model.

baux.ENN(
    train_x,
    train_y,
    train_yvar=None,
    *,
    scale_x=False,
    index_driver=NeighborIndex.FLAT,
    work_dir=None,
    enn_storage=None,
    y_bounds=None,
    **options,
)

train_x: (N, D). train_y and optional train_yvar: (N, M). Unlike enn_init, this constructor requires two-dimensional output arrays.

index_driver selects the backend. Extra options include device, index, storage, metric_learning, geometry and local_k. y_bounds supplies (M, 2) output bounds.

add(x, y, yvar=None) appends in place. posterior(x, params, flags=...) returns moments; posterior_draw(x, params, function_seeds=..., flags=...) returns draws and neighbor IDs.

NumPy queries return ENNNormal. Supported device queries return a native Posterior. The presence of a device argument does not imply every operation runs there; inspect capabilities.

baux.ENNFitter

Source

Track fitting statistics for a mutable ENN model.

baux.ENNFitter(k, rng, *, infer_aleatoric_variance_scale=True)

k: neighbor count. rng: NumPy generator. infer_aleatoric_variance_scale: whether to fit the aleatoric scale.

Call tell(x, y, yvar) to update statistics, then ask(model, num_candidates=..., num_samples=...) to get ENNParams. For the functional equivalent, use enn_fit.

baux.Telemetry

Source

Timings and candidate count from optimizer work.

baux.Telemetry(dt_fit, dt_sel, dt_gen=0.0, dt_tell=0.0, num_candidates=0)

dt_fit, dt_sel, dt_gen and dt_tell are durations in seconds. num_candidates is the candidate count. Available as state.telemetry or optimizer.telemetry().

baux.TellPredictionError

Source

Ingestion succeeded but retrieving predictions failed.

class baux.TellPredictionError(RuntimeError)

A RuntimeError subclass with observations_accepted=True. In the in-place optimizer, retry optimizer.posterior_mu(x) rather than submitting the same observations again. This exception does not classify errors from ingestion itself.

baux.enn_optimizer

Source

Construct the native ENN optimizer handle.

baux.enn_optimizer(bounds, k=10, num_init=10, seed=None, config=None)

bounds: (D, 2) array; k: neighbor count; num_init: initialization budget. Returns a native optimizer handle. config uses the native configuration representation.

For Python configuration records and functional state, use init; for the in-place Python wrapper, use create_optimizer.

baux.create_zero

Source

Construct the native surrogate-free optimizer handle.

baux.create_zero(bounds, num_init=10, seed=None, config=None)

bounds: (D, 2) array; num_init: initialization budget. Returns a native handle. config uses the native representation. The Python configuration preset is turbo_zero.
