All functional transitions return new state. Keep the returned state for the next call. BAUX maximizes objective values; negate a loss when minimizing. Coordinate batches use (N, D) arrays. Standard single-objective search uses (N,) rewards; multi-output search requires a compatible configuration. complete currently accepts scalar rewards only.

baux.init

Source

Create an optimizer and its initial state.

baux.init(domain, config=None, *, pipe=None, key=None, seed=None, low=-1.0, high=1.0)

domain: a (D, 2) array of lower and upper bounds, a Space, or a parameter template. low and high apply when compiling a template.

Pass either config or pipe. With neither, the default uses a TuRBO region, no surrogate and random acquisition. Use baux.enn() to enable an ENN surrogate.

Returns OptimizerState. key takes precedence over seed. Unsupported configurations or malformed bounds raise ValueError.

Example 
import numpy as np
import baux

domain = np.array([[-2.0, 2.0], [-2.0, 2.0]])
state = baux.init(domain, seed=42)
for _ in range(6):
    state, batch = baux.ask(state, num_arms=2)
    y = -np.sum(batch.points**2, axis=-1)
    state, _ = baux.tell(state, batch, y)

assert state.num_observations == 12

baux.ask

Source

Propose points to evaluate.

baux.ask(state, num_arms=None, *, n=None)

Returns (next_state, batch). Keep next_state for the subsequent submission; batch.points has shape (N, D).

num_arms defaults to one. n is an alias; supplying both raises ValueError. The count must be positive.

For regional search, proposals become pending in the returned state. Use batch.ids to report results through complete. The objective is not called here.

baux.tell

Source

Record an evaluated batch and update the search.

baux.tell(state, x, y, *, y_var=None)

x: an AskBatch, a (N, D) coordinate array, a single (D,) point, or parameters matching the state's Space. y: objective values with one row per point. Larger values are better.

y_var: optional observation variances, with the same shape as y. Returns (next_state, fitted_mu); without a surrogate, the second result is the submitted values.

In regional search, tell is the ordered, whole-batch path. It submits coordinates even when given an AskBatch; it does not validate that object's ticket IDs. Use complete for ticket-based or out-of-order completion.

baux.step

Source

Propose, evaluate and record one batch.

baux.step(state, objective, *, num_arms=1, use_pytree=False)

Calls objective(batch.points) with shape (num_arms, D), then submits the returned values. Returns (next_state, y).

With use_pytree=True and a structured domain, the objective receives one decoded parameter tree for a single arm, or a tree with stacked leaves for multiple arms. Return one objective row per arm.

baux.complete

Source

Record results for pending regional tickets.

baux.complete(state, ids, y, *, y_var=None)

ids: an AskBatch or a sequence of AskId values. y: scalar rewards in the same order, shape (K,) or (K, 1). Optional y_var must match. Multi-output completion is not supported by this function.

Returns the updated OptimizerState. A subset may finish before the rest of its batch, and batches may finish out of order.

Requires regional search. Wrong token types raise TypeError; unknown, duplicated, resolved or invalidated tickets are rejected. After a region restarts, its old tickets cannot be completed.

Example 
import numpy as np
import baux

domain = np.array([[-1.0, 1.0], [-1.0, 1.0]])
pipe = baux.enn(k=5) | baux.regions(2)
state = baux.init(domain, pipe, seed=42)
state, batch = baux.ask(state, num_arms=4)
assert len(state.pending_ids) == 4
state = baux.complete(state, batch.ids[:2], np.array([0.5, 0.8]))
state = baux.cancel(state, batch.ids[2:])
assert len(state.pending_ids or ()) == 0

baux.cancel

Source

Retire pending regional tickets without an observation.

baux.cancel(state, ids)

Accepts an AskBatch or sequence of AskId values and returns the updated state. Does not record a reward or count a failed evaluation as a trust-region failure.

Cancellation only updates optimizer bookkeeping. The caller must stop any external worker if that is desired.

baux.restart_region

Source

Start a regional slot again at a supplied center.

baux.restart_region(state, slot, center)

slot: region index. center: one (D,) point or a structured parameter value. Returns (next_state, abandoned_ids).

Pending evaluations in that slot are invalidated. The caller owns external jobs and decides whether to cancel them. Requires regional search; otherwise raises RuntimeError.

baux.import_observations

Source

Add measurements collected outside the current pending batch.

baux.import_observations(state, x, y, *, y_var=None)

Uses the same x, y and y_var shapes as tell. Returns (next_state, fitted_mu).

Does not complete pending tickets. Use this for historical data or an explicitly chosen import of a late result, not as a substitute for completing a live evaluation.

baux.posterior_mu

Source

Predict the fitted surrogate mean at query points.

baux.posterior_mu(state, x)

x: (N, D) coordinates or parameters matching the state's domain. Returns a read-only NumPy array in the objective's units. Does not advance the optimizer. Requires a fitted surrogate.

baux.OptimizerState

Source

The state returned by the functional optimizer.

class baux.OptimizerState  (frozen dataclass; constructed via baux.init)

Create it with init. Each transition returns a new state; retain the old one only if you need a branch or checkpoint.

x_obs, y_obs: observation arrays. num_observations, num_regions, tr_length: current search information. best_x, best_params, best_y: incumbent coordinates, decoded parameters and value, or None before observations.

pending_ids: raw integer IDs for inspection; pass the typed batch.ids to complete or cancel. fork(key=None, *, seed=None) creates another search branch. Checkpoints and keys covers persistence and branching.

baux.AskBatch

Source

Points and evaluation identities returned by a proposal.

baux.AskBatch(ids, points, spec=None, weights=None)

points: read-only (N, D) coordinates. ids: one AskId per row. len(batch) is N.

params: tuple of decoded parameter trees, one per row. stacked: one tree with a leading batch axis on its leaves. For an unstructured domain, these expose the coordinate rows and matrix.

Keep the batch paired with the state returned by ask. Tickets support asynchronous completion only when regional search is enabled.

baux.AskId

Source

An opaque evaluation ticket.

baux.AskId(value)

Keep tokens returned in batch.ids and pass them back unchanged. aid.value exposes the unsigned 64-bit integer for inspection. Tickets are immutable, hashable and ordered.
