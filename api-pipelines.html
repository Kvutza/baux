baux.enn

Source

Configure an ENN surrogate.

baux.enn(
    *,
    k=10,
    num_samples=100,
    scale_x=False,
    index=NeighborIndex.FLAT,
    storage=None,
    metric_learning='none',
    geometry='euclidean',
    local_k=4,
    stiefel=None,
    affine=None,
    tied_dims=None,
)

Returns a Transform. k: neighbor count. num_samples: leave-one-out fitting sample budget; None disables that fitting setting. scale_x: input scaling.

index: a NeighborIndex or accepted driver name such as "flat", "usearch", "metal" or "cuda". Hardware support depends on the build. storage: optional storage selection.

metric_learning, geometry, local_k, tied_dims: input metric and grouping settings. stiefel and affine: optional output maps.

When the incoming acquisition is random, this transform selects UCB, or Pareto selection if num_samples=None. An already selected non-random acquisition is preserved.

Example 
import numpy as np
import baux

domain = np.array([[-2.0, 2.0], [-2.0, 2.0]])
pipe = baux.enn(k=8) | baux.ucb(beta=1.5) | baux.lhd(num_init=6) | baux.regions(2)
state = baux.init(domain, pipe, seed=42)
state, y = baux.step(state, lambda x: -np.sum(x**2, axis=-1), num_arms=2)
assert state.num_observations == 2
assert len(y) == 2

baux.gp

Source

Configure the Gaussian-process surrogate.

baux.gp()

Returns a Transform. If the incoming acquisition is random, selects Thompson sampling. An existing non-random acquisition is preserved.

baux.zero

Source

Configure search without a surrogate.

baux.zero()

Returns a Transform that selects NoSurrogate, random acquisition and a TuRBO region if regions were disabled. Existing active trust-region settings are preserved.

baux.ucb

Source

Select candidates by mean plus uncertainty.

baux.ucb(beta=2.0)

Returns a Transform using mu + beta * se. beta must be finite and positive. Adds an ENN surrogate if none is configured, and enables ENN fitting when it was disabled.

baux.thompson

Source

Select candidates using posterior function draws.

baux.thompson()

Returns a Transform. Adds an ENN surrogate if none is configured, and enables ENN fitting when it was disabled. Use enn_sample to query function draws directly.

baux.pareto

Source

Select from the mean–uncertainty frontier.

baux.pareto()

Returns a Transform using non-dominated sorting over predicted mean and uncertainty. Adds an ENN surrogate if none is configured. This is an acquisition rule; it does not by itself configure multi-objective optimization.

baux.random_acq

Source

Select candidates without surrogate scores.

baux.random_acq()

Returns a Transform choosing random acquisition. It leaves the candidate sampler and surrogate configuration in place; use zero to remove the surrogate.

baux.lhd

Source

Set Latin-hypercube initialization.

baux.lhd(num_init=10, *, only=False)

num_init: initial evaluation budget. Returns a Transform. With only=True, also disables the surrogate and trust region for LHD-only exploration.

baux.sobol

Source

Use a scrambled Sobol candidate sampler.

baux.sobol(num_candidates=None, *, per_arm=None, num_pert=None)

Returns a Transform. num_candidates: total candidate budget; per_arm: budget per requested arm. Omitted values preserve the current configuration. num_pert sets the perturbation count when supplied.

baux.raasp

Source

Use sparse coordinate perturbations for candidates.

baux.raasp(num_pert=20, *, num_candidates=None, per_arm=None, driver=RAASPDriver.ORIG)

Returns a Transform. num_pert: expected perturbation count, capped by dimension; num_candidates and per_arm set candidate budgets. Omitted budgets preserve the current configuration.

driver uses RAASPDriver from baux.turbo.config.candidates. The default is RAASPDriver.ORIG.

baux.uniform_pert

Source

Use uniform random candidate perturbations.

baux.uniform_pert(num_candidates=None, *, per_arm=None, num_pert=None)

Returns a Transform. num_candidates, per_arm and num_pert override the respective candidate settings when supplied. This configures candidate generation; acquisition chooses which candidates to evaluate.

baux.regions

Source

Enable multiple local search regions.

baux.regions(
    count=4,
    *,
    sharing='ellipsoid_ball',
    allocation='incumbent_ucb1',
    success_tolerance=3,
    failure_tolerance=5,
    length=None,
)

Returns a Transform. count is the positive number of regions. Sharing choices are "box_contain", "ellipsoid_ball", "nearest_center" and "origin_only". The transform defaults to "ellipsoid_ball".

Allocation choices are "incumbent_ucb1", "least_trials" and "joint_acquisition". Positive success and failure tolerances control region resizing; length supplies explicit bounds.

For restart policy, fixed-radius control or per-region acquisitions, use RegionalSearchPolicy. See multiple regions and workers for a complete loop.

baux.tr_bounds

Source

Set trust-region length limits.

baux.tr_bounds(*, length_init=0.8, length_min=0.0078125, length_max=1.6)

Returns a Transform. Requires 0 < length_min <= length_init <= length_max. Lengths are in normalized coordinates.

Updates length bounds on a regional policy. For other policies, installs a TurboTrustRegion with these bounds.

baux.with_geometry

Source

Change the ENN dissimilarity geometry.

baux.with_geometry(model, geometry, local_k=4)

geometry: "euclidean", "conformal", "hyperbolic" or "wasserstein". local_k must be positive. See ENN predictions for the formulas behind these names.

With an ENNState or ENN, returns a model retaining the observations. With a configuration or Transform, returns its updated configuration.

With an OptimizerState, this function initializes a new optimizer and does not retain the optimization history. Configure geometry before starting a search.

baux.stein

Source

Configure prediction shrinkage toward a subspace.

baux.stein(target=None, frame=None, *, rank=None)

Use stein(rank=F) to build a pipeline transform, or stein(enn_state, frame) to apply a supplied Stiefel frame. A rank requests a frame estimated from observed outputs.

The basis has shape (M, F). Use Stiefel.from_factors to orthonormalize supplied factors. This API does not provide a James–Stein risk guarantee.

Applying the transform to an OptimizerState initializes a new optimizer; configure it before collecting observations.

baux.calibrate

Source

Configure an affine correction to predictions.

baux.calibrate(target=None, affine=None, *, alpha=None)

Use calibrate(affine=map) for a supplied Affine, or calibrate(alpha=0.1) to request a fitted correction and residual-quantile scale. Applying it to an ENNState returns a new state.

alpha is a miscoverage setting in (0, 1). Adaptive optimization observations do not automatically satisfy exchangeability or a coverage guarantee.

Applying it to an OptimizerState initializes a new optimizer; configure it before collecting observations.

baux.Transform

Source

A composable optimizer configuration update.

baux.Transform(name, fn)

Transform(name, fn) wraps fn(config) -> OptimizerConfig. Combine stages with a | b; the left stage runs first. Call pipe() to apply it to the default configuration, or pipe(config) to modify an existing one.

baux.chain

Source

Apply configuration stages from left to right.

baux.chain(*steps)

Returns an OptimizerConfig. A configuration passed among the stages replaces the accumulated configuration; subsequent transforms modify it. Pass the result to init or create_optimizer.
