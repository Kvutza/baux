baux.capabilities

Source

Inspect build support and optional hardware availability.

baux.capabilities(*, probe=False)

Returns a tuple of BackendCapabilities. With probe=False, reads build support without active hardware checks. With probe=True, probes hardware too.

Read the operation lists as well as available: a backend may be available while a particular operation is missing or uses a host fallback.

baux.BackendCapabilities

Source

Support information for one backend.

baux.BackendCapabilities(
    name: Literal["cpu", "cuda", "metal", "opencl"],
    compiled: bool,
    available: bool | None,
    reason: str | None,
    direct_operations: tuple[str, ...],
    fallback_operations: tuple[str, ...],
    missing_operations: tuple[str, ...],
    host_operations: tuple[str, ...],
    array_frameworks: tuple[str, ...],
)

name: backend name. compiled: included in this native build. available: hardware result, or None when not probed. reason: diagnostic text when relevant.

direct_operations, fallback_operations, missing_operations and host_operations distinguish operation support. array_frameworks lists detected optional array packages. Returned by capabilities.

baux.Device

Source

Select a native compute device.

baux.Device(name='auto')

name selects a device, with "auto" as the default. memory_info() returns device memory information. Use capabilities(probe=True) to check installed backend support before choosing a device.

baux.optuna.Sampler

Source

Use BAUX to generate trials in an Optuna study.

baux.optuna.Sampler(
    space: Mapping[str, FloatDistribution],
    *,
    config: OptimizerConfig | None = None,
    seed: int | None = None,
)

Import explicitly with from baux.optuna import Sampler; requires the optuna extra. space: a fixed mapping of names to Optuna FloatDistribution objects. Logarithmic floats are supported.

Use one sampler per study, n_jobs=1 and one generating process. Integers, stepped or conditional spaces, and multi-objective studies are rejected. A new sampler can use completed trials but does not restore the original search trajectory.

baux.experimental.program

Source

Compile and execute experimental array programs.

baux.experimental.program

Import with from baux.experimental import program. This module exposes compile, TensorSpec, Buffer, Executable and register, with backend-specific runtime requirements.

See the module source for the experimental interface and supported input forms. It is separate from the optimizer's ask/tell API.
