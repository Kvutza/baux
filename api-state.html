Checkpoints and keys

All symbols Optimization loop Pipelines Parameter domains ENN predictions Checkpoints and keys Configuration In-place interfaces Runtime and integrations

A checkpoint saves optimizer state. A key controls randomness. Neither saves the external evaluator or running worker jobs. Continue a restored run with the same observations and submission order when reproducibility matters.

freeze · thaw · digest · key · Key · split · fold · scan · pmap

baux.freeze

Source

Serialize an optimizer checkpoint.

baux.freeze(state)

Returns bytes. Save them and restore with thaw, supplying a compatible initial state. The checkpoint contains optimizer state, including pending evaluations; it does not save external worker jobs or evaluator state.

The BLAKE3 tag detects corruption. It is not an authentication signature.

Example 
import numpy as np
import baux

domain = np.array([[-2.0, 2.0], [-2.0, 2.0]])
blank = baux.init(domain, baux.turbo_zero(), seed=123)
state, batch = baux.ask(blank, 2)
y = -np.sum(batch.points**2, axis=-1, keepdims=True)
state, _ = baux.tell(state, batch, y)
raw = baux.freeze(state)
restored = baux.thaw(blank, raw)
assert restored.epoch == state.epoch
assert restored.seed == state.seed
assert restored.num_observations == state.num_observations
assert np.array_equal(baux.ask(state, 2)[1].points, baux.ask(restored, 2)[1].points)

baux.thaw

Source

Restore a checkpoint against a compatible state template.

baux.thaw(state, data)

state: a state initialized with the expected domain and configuration. data: bytes from freeze. Returns the restored OptimizerState.

Checks the format, integrity and compatibility; malformed or incompatible payloads are rejected. To reproduce subsequent proposals, preserve the evaluator results and their submission order too.

baux.digest

Source

Get the optimizer state's content digest.

baux.digest(state)

Returns a 64-character hexadecimal string. Use it to compare saved optimizer states. It does not identify the external evaluator, data source or running workers.

baux.key

Source

Create a random key or retrieve one from a state.

baux.key(source=None)

source may be an integer seed, bytes, an array or an object exposing key. With None, draws fresh operating-system entropy. Returns a Key.

baux.Key

Source

A splittable random key.

baux.Key(source=None)

Use key, split and fold to create and derive keys. Reusing a key reproduces its deterministic stream. Reproducing a search also requires the same observations and transition order.

baux.split

Source

Derive child keys from a parent key.

baux.split(k, n=2)

Returns a tuple of n keys without changing k. Default n=2. Use a different child for each search branch or draw stream.

baux.fold

Source

Derive a key using an integer tag.

baux.fold(k, tag)

Returns a new key. The tag is reduced modulo 2**64; the parent is unchanged. Useful for giving a step or branch a repeatable key.

baux.scan

Source

Run several sequential optimization rounds.

baux.scan(state, key=None, steps=0, eval_fn=None, num_arms=1)

Keyed form: scan(state, key, steps, eval_fn, num_arms=1) returns (final_state, next_key, records). The evaluator receives the coordinate batch; records contain step, best_y and a lazily computed digest.

Convenience form: scan(state, objective, steps=N) returns (final_state, values) and uses decoded parameters for a structured domain. The two forms have different return values. steps must be non-negative.

Example 
import numpy as np
import baux

domain = np.array([[-2.0, 2.0], [-2.0, 2.0]])
state = baux.init(domain, baux.turbo_zero(), seed=0)

def objective(x):
    return -np.sum(x**2, axis=-1, keepdims=True)

final_state, key_out, traces = baux.scan(
    state,
    key=baux.key(42),
    steps=4,
    eval_fn=objective,
    num_arms=1,
)
assert final_state.num_observations == 4
assert len(traces) == 4
assert traces[-1]["step"] == 3

root_key = baux.key(0)
subkeys = baux.split(root_key, 3)
assert len(subkeys) == 3

def branch_fn(idx, branch_state, k):
    s_end, _, _ = baux.scan(branch_state, key=k, steps=2, eval_fn=objective)
    return idx, s_end.best_y

results = baux.pmap(state, root_key, 3, branch_fn)
assert len(results) == 3
assert [r[0] for r in results] == [0, 1, 2]

baux.pmap

Source

Run independent search branches in worker threads.

baux.pmap(state, key, branches, branch_fn)

Calls branch_fn(index, branch_state, branch_key) once per branch and returns results in branch-index order. Each branch starts from state.fork(child_key).

branches must be non-negative; zero returns an empty list. This is a local thread pool, not a device mapping or distributed scheduler. Evaluator thread safety remains the caller's responsibility.
