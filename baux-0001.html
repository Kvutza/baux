Baux

baux is a black-box optimization library with a Rust core and a Python API. Give it a parameter space and a function to evaluate. It uses the returned values to propose the next parameters, without requiring gradients from your function.

Search over numeric bounds or structured parameters, use a surrogate to guide proposals, and run several local search regions together. You control when and where evaluations run through the ask/tell interface.

1. Start with a Function

This example searches six bounded parameters. ask proposes points; your function evaluates them; tell records the results. BAUX maximizes values, so return the negative of a loss you want to minimize.

import numpy as np
import baux


def objective(x):
    return -np.sum((x - 0.4) ** 2, axis=1)


bounds = np.tile([-2.0, 2.0], (6, 1))
pipe = baux.enn(k=10) | baux.ucb(beta=2.0)
state = baux.init(bounds, pipe, key=baux.key(0))

for _ in range(15):
    state, batch = baux.ask(state, num_arms=4)
    state, _ = baux.tell(state, batch, objective(batch.points))

print(state.best_x, state.best_y)

batch.points has one row per proposed point. Return one value per row, or several columns for a vector objective. The pipeline above uses an ENN surrogate and UCB acquisition; the configuration reference describes their options.

2. Use It for Your Problem

  • Structured parameters — Search dictionaries and dataclasses containing log scales, angles, mixtures and discrete choices. Read the proposed values from batch.params.
  • Multiple regions and workers — Explore several centers, return evaluations as workers finish, and save or resume a search.
  • Surrogate predictions — Fit ENN to existing observations, query predictions and draw samples.
  • Interactive examples — Explore synthetic objectives and the tokamak control example.

See the API reference for signatures, array shapes and configuration options. The source repository contains the Rust implementation and Python frontend.
