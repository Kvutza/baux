API Reference

1. State Transitions

OptimizerState is an immutable record exposing the incumbent .best_x, .best_y, decoded .best_params, observation arrays .x_obs and .y_obs (.num_observations), regional epoch counter .epoch, trust-region length .tr_length, and content-addressed .key derived from baux.digest(state).

baux.init(
    domain: np.ndarray | PyTreeSpec | Any,
    config: OptimizerConfig | Transform | None = None,
    *,
    pipe: OptimizerConfig | Transform | None = None,
    key: Key | None = None,
    seed: int | np.random.Generator | None = None,
    low: Any = -1.0,
    high: Any = 1.0,
) -> OptimizerState

baux.ask(state, num_arms=1) returns (next_state, batch), where AskBatch carries proposal IDs, coordinate arrays, decoded parameter dictionaries, and stacked tensors.

baux.tell(state, x, y, y_var=None) appends observations and returns (next_state, mu). baux.step(state, objective) runs one ask -> evaluate -> tell cycle.

baux.scan(state, key, steps, eval_fn, num_arms) folds transitions across rounds. baux.pmap(state, key, branches, branch_fn) forks snapshots and splits keys across worker threads.

Asynchronous regional completions and cancellations use baux.complete(state, ids, y, y_var=None) and baux.cancel(state, ids). States hash via baux.digest(state) (BLAKE3) and serialize via baux.freeze(state) and baux.thaw(state, data).

2. PRNG Keys

baux.key(seed) constructs a 128-bit (u64, u64) SplitMix64 key from an integer, byte buffer, array, state digest, or OS entropy, seeding deterministic ChaCha12 and optimizer streams. baux.split(k, n) partitions \(k\) into \(n\) subkeys, and baux.fold(k, tag) mixes in an integer tag without mutating \(k\), keeping proposal generation, hyperparameter fitting, and posterior sampling independent.

3. Pipeline Transforms

Pipelines compose Transform stages into an OptimizerConfig via baux.chain(*steps) or t1 | t2.

Initialization and perturbation use baux.lhd(num_init=10), baux.sobol(num_candidates=1024), baux.raasp(num_pert=20), and baux.uniform_pert(num_candidates=1024). Surrogates attach via baux.enn(k=10, geometry="euclidean"), baux.gp(), or baux.zero(); acquisitions attach via baux.ucb(beta=2.0), baux.thompson(), baux.pareto(), or baux.random_acq().

Geometry and regional layout are configured with baux.tr_bounds(length_init=0.8), baux.regions(count=4, sharing="ellipsoid_ball"), baux.with_geometry(target, "hyperbolic"), baux.stein(target, rank=4), and baux.calibrate(target, alpha=0.1).

4. PyTree Domains & Codomain Operators

Parameter spaces are written as nested Python dicts, tuples, and lists of leaf charts, compiled by baux.pytree_bounds(tree) into a PyTreeSpec.

Domain leaf charts include baux.Log(low, high), baux.Periodic(low, high), baux.Simplex(dim), and baux.categorical(categories, encoding="auto"). baux.ravel(tree, spec) and baux.unflatten(flat, spec) map between nested Python values and flat solver coordinates. Multi-output codomain operators use baux.Stiefel(loadings) (with baux.stein) and baux.Affine(scale, shift, conformal_q=1.0) (with baux.calibrate).

5. ENN Surrogate

baux.enn_init(train_x, train_y, scale_x=True) builds an immutable surrogate state; baux.append(state, x, y) appends observations via copy-on-write; baux.fit(state, k=10, key=k0) selects scale parameters by subsampled leave-one-out log-pseudolikelihood.

baux.posterior(state, x, params) evaluates posterior mean, aleatoric standard error, and epistemic standard error at x. baux.sample(state, x, params, key=k1, num_draws=16) returns (draws, idx), with function draws of shape (batch, metrics, num_draws) and neighbor indices of shape (batch, k).

6. Adapters

baux.create_optimizer(bounds=bounds, config=config, rng=rng) wraps the functional core in a stateful Optimizer exposing opt.ask(num_arms), opt.tell(x, y), opt.posterior_mu(x), and opt.telemetry(). from baux.optuna import Sampler provides an Optuna BaseSampler over continuous FloatDistribution spaces. baux.capabilities(probe=False) lists compiled and active backends ("cpu", "metal", "cuda", "opencl").
