API Reference

Top-level import baux exposes a lazy-loaded namespace (__getattr__) resolving functional state transitions, composable pipeline combinators, manifold domain charts, standalone Epistemic Nearest Neighbor (ENN) surrogates, and Rust-backed primitives on demand without eagerly importing optional array or compiler frameworks. Across all entrypoints, flat parameter matrices x have shape (N, D) (float64) inside natural domain bounds [low, high], while objective arrays y (maximization convention) and optional heteroscedastic observation variances y_var have shape (N,) for scalar targets or (N, M) (float64) for multi-output objectives. Pure functional transitions (baux.init, baux.ask, baux.tell, baux.enn_init, baux.enn_append) operate on immutable, content-addressed copy-on-write snapshots (OptimizerState, ENNState) whose array properties return read-only views (writeable=False), whereas Optimizer and ENN provide stateful in-place harnesses over the same native execution engine.

baux.complete(

Complete any non-empty subset of pending multi-region evaluation AskId tokens in arbitrary arrival order.

Parameters
  • state (OptimizerState) — Multi-region optimizer snapshot (state.identified == True) with pending proposals.
  • ids (AskBatch | tuple[AskId, ...] | list[AskId]) — Batch or sequence of K typed AskId tokens to resolve.
  • y (array-like of shape (K,) or (K, 1)) — Finite scalar objective values corresponding 1-to-1 with ids.
  • y_var (array-like of shape (K,) or (K, 1) | None, keyword-only, default None) — Optional finite nonnegative observation noise variances.
Returns
OptimizerState — Updated snapshot with completed observations ingested and resolved ids retired from pending_ids.
Raises
TypeError if ids contains non-AskId elements; ValueError if y is not shape (K,)/(K, 1) or if any ID is unknown, already resolved, or belongs to a stale regional generation.
Notes
Each AskId carries (slot, generation) provenance in the native regional ledger. Active completions append globally to the surrogate store immediately; a region slot's TuRBO side length and success/failure counters adapt once every arm in its pending group settles (via complete or cancel) and its generation matches the slot's active epoch. If a slot was restarted via baux.restart_region, its abandoned IDs belong to a stale generation and are rejected by complete; ingest late measurements from abandoned runs via baux.import_observations instead.
