Optimization loop

Create state, propose points, submit results and manage pending evaluations.

baux.init Create an optimizer and its initial state.
baux.ask Propose points to evaluate.
baux.tell Record an evaluated batch and update the search.
baux.step Propose, evaluate and record one batch.
baux.complete Record results for pending regional tickets.
baux.cancel Retire pending regional tickets without an observation.
baux.restart_region Start a regional slot again at a supplied center.
baux.import_observations Add measurements collected outside the current pending batch.
baux.posterior_mu Predict the fitted surrogate mean at query points.
baux.OptimizerState The state returned by the functional optimizer.
baux.AskBatch Points and evaluation identities returned by a proposal.
baux.AskId An opaque evaluation ticket.

Pipelines

Choose a surrogate, acquisition rule, candidate sampler and regional policy.

baux.enn Configure an ENN surrogate.
baux.gp Configure the Gaussian-process surrogate.
baux.zero Configure search without a surrogate.
baux.ucb Select candidates by mean plus uncertainty.
baux.thompson Select candidates using posterior function draws.
baux.pareto Select from the mean–uncertainty frontier.
baux.random_acq Select candidates without surrogate scores.
baux.lhd Set Latin-hypercube initialization.
baux.sobol Use a scrambled Sobol candidate sampler.
baux.raasp Use sparse coordinate perturbations for candidates.
baux.uniform_pert Use uniform random candidate perturbations.
baux.regions Enable multiple local search regions.
baux.tr_bounds Set trust-region length limits.
baux.with_geometry Change the ENN dissimilarity geometry.
baux.stein Configure prediction shrinkage toward a subspace.
baux.calibrate Configure an affine correction to predictions.
baux.Transform A composable optimizer configuration update.
baux.chain Apply configuration stages from left to right.

Parameter domains

Encode structured, categorical and constrained parameters.

baux.Space Compile structured parameters into optimizer coordinates.
baux.PyTreeSpec The compiled layout used by a structured search.
baux.Log A positive parameter represented on a logarithmic scale.
baux.Periodic A periodic parameter represented by two coordinates.
baux.Simplex A vector of non-negative components that sum to one.
baux.categorical Define a parameter that chooses from discrete options.
baux.Categorical A discrete domain and its coordinate encoding.
baux.ravel Encode structured parameters as solver coordinates.
baux.unflatten Decode one coordinate vector into parameters.
baux.unflatten_batch Decode a coordinate batch into individual parameter trees.
baux.unflatten_stacked Decode a batch into one tree with batched leaves.
baux.pytree_bounds Build a domain specification from a parameter template.
baux.LeafSpec The path and coordinate slice for one parameter leaf.
baux.Stiefel Store a basis for output-subspace shrinkage.
baux.Affine Store a per-output correction to mean and uncertainty.

ENN predictions

Create a dataset, fit parameters, predict and draw functions.

baux.enn_init Create an ENN dataset and neighbor index.
baux.enn_append Append observations to an ENN state.
baux.enn_fit Fit ENN variance scales for a neighbor count.
baux.enn_posterior Predict means and uncertainty at query points.
baux.enn_sample Draw functions from the ENN prediction model.
baux.ENNState A dataset and index for functional ENN queries.
baux.ENNParams Parameters required for an ENN prediction.
baux.Posterior A native posterior result for device queries.
baux.NeighborIndex Select a nearest-neighbor backend.
baux.DistanceMetric Select the index distance.

Checkpoints and keys

Save search state, control randomness and branch a run.

baux.freeze Serialize an optimizer checkpoint.
baux.thaw Restore a checkpoint against a compatible state template.
baux.digest Get the optimizer state's content digest.
baux.key Create a random key or retrieve one from a state.
baux.Key A splittable random key.
baux.split Derive child keys from a parent key.
baux.fold Derive a key using an integer tag.
baux.scan Run several sequential optimization rounds.
baux.pmap Run independent search branches in worker threads.

Configuration

Use configuration records and presets for explicit control.

baux.OptimizerConfig The complete optimizer configuration.
baux.RegionalSearchPolicy Configure region sharing, allocation and restart behavior.
baux.TrustRegionBounds Initial, minimum and maximum region lengths.
baux.turbo_enn Create an ENN optimizer configuration preset.
baux.turbo_one Create a Gaussian-process TuRBO configuration.
baux.turbo_zero Create a surrogate-free trust-region configuration.
baux.lhd_only Create a Latin-hypercube exploration configuration.

In-place interfaces

Use mutable optimizer and ENN objects, or access native handles.

baux.create_optimizer Create an optimizer that updates in place.
baux.Optimizer An in-place ask/tell optimizer.
baux.ENN A mutable ENN dataset and prediction model.
baux.ENNFitter Track fitting statistics for a mutable ENN model.
baux.Telemetry Timings and candidate count from optimizer work.
baux.TellPredictionError Ingestion succeeded but retrieving predictions failed.
baux.enn_optimizer Construct the native ENN optimizer handle.
baux.create_zero Construct the native surrogate-free optimizer handle.
baux.create_lhd Construct the native LHD optimizer handle.

Runtime and integrations

baux.capabilities Inspect build support and optional hardware availability.
baux.BackendCapabilities Support information for one backend.
baux.Device Select a native compute device.
baux.optuna.Sampler Use BAUX to generate trials in an Optuna study.
baux.experimental.program Compile and execute experimental array programs.
