Work with Structured Parameters

Pass a dictionary, tuple or dataclass template to baux.init. Use Log for positive scales, Periodic for angles, Simplex for mixture weights and categorical for discrete choices. After ask, evaluate the decoded objects in batch.params.

1. Parameter Coordinate Maps

A structured domain tells the optimizer how to encode parameters as coordinates and decode proposals for evaluation. baux.init accepts nested dictionaries, tuples and dataclasses. For such a domain, batch.points contains solver coordinates and batch.params contains decoded parameters. Each leaf specifies its own map; the examples below show how that choice affects distance and valid proposals.

  • Log-scale intervals (baux.Log): On \([a, b] \subset \mathbb {R}_+\), \[ \psi (x) = \frac {\log x - \log a}{\log b - \log a} \in [0, 1], \qquad \rho (u) = a\left (\frac {b}{a}\right )^{\Pi _{[0,1]}(u)}, \] so uniform steps in \(u\) correspond to constant multiplicative ratios in \(x\).
  • Periodic intervals (baux.Periodic): On \(\lbrack a, b\rparen \) of period \(P = b - a\) with phase \(\phi (x) = \tfrac {2\pi (x - a)}{P}\), circle embedding and \(\operatorname {atan2}\) decoding, \[ \psi (x) = \left (\frac {1}{2} + \frac {\cos \phi (x)}{2\pi },\; \frac {1}{2} + \frac {\sin \phi (x)}{2\pi }\right ), \qquad d_{\mathcal {U}}\bigl (\psi (x), \psi (x')\bigr ) = \frac {1}{\pi }\left |\sin \left (\frac {\phi (x) - \phi (x')}{2}\right )\right |, \] avoid artificial jumps across the wrap boundary \(a \equiv b\).
  • Probability simplices (baux.Simplex): On \(\Delta ^{d-1}\), the square-root map onto the positive unit sphere and radial normalization, \[ \psi (p) = \bigl (\sqrt {p_1}, \dots , \sqrt {p_d}\bigr ) \in S_+^{d-1}, \qquad \rho (u) = \frac {\max (u, 0)^{\odot 2}}{\Vert \max (u, 0)\Vert _2^2}, \] give squared coordinate distance \(\sum _j(\sqrt {p_j}-\sqrt {q_j})^2\), equal to twice squared Hellinger distance under the convention \(H^2(p,q)=\tfrac 12\sum _j(\sqrt {p_j}-\sqrt {q_j})^2\). The decoder returns the uniform distribution when all clipped coordinates are zero.
  • Discrete sets (baux.categorical): Finite choices \(\{1, \dots , C\}\) map to equal-norm orthogonal or Rademacher codewords \(\psi (c) \in \mathbb {R}^{d_c}\) (Achlioptas [Ach03]), reducing nearest-codeword decoding to \(\rho (u) = \arg \max _c \langle u, \psi (c)\rangle \).

2. Linear Subspace Shrinkage

Vector observations may contain a component aligned with a known subspace and a residual outside it. baux.Stiefel.from_factors orthonormalizes a full-rank basis \(L\) to obtain \(V\). With \(P=VV^\top \), a contraction factor \(\alpha \in [0,1]\) preserves the projected component and reduces the residual:

\[ \hat {\theta }_\alpha = P y + \alpha (I_M - P)y. \]

To see the tradeoff, suppose \(y=\theta +\eta \in \mathbb {R}^M\) with zero-mean noise, a fixed subspace of rank \(1 \le r < M\), and a fixed \(\alpha \). Write \(v_\parallel =\mathbb {E}\Vert P\eta \Vert ^2\), \(v_\perp =\mathbb {E}\Vert (I-P)\eta \Vert ^2>0\), and \(b_\perp ^2=\Vert (I-P)\theta \Vert ^2\). Orthogonality gives mean squared error \(\mathcal {R}(\alpha )=v_\parallel +(1-\alpha )^2 b_\perp ^2+\alpha ^2 v_\perp \). Its minimizer is:

\[ \alpha ^* = \frac {b_\perp ^2}{b_\perp ^2 + v_\perp }, \qquad \mathcal {R}(\alpha ^*) = v_\parallel + \frac {v_\perp b_\perp ^2}{b_\perp ^2 + v_\perp } < v_\parallel + v_\perp = \mathcal {R}(1). \]

This is an oracle calculation: the off-subspace signal energy is unknown. baux.stein instead computes a contraction from the predicted residual energy and predicted variances. That fitted rule is not the positive-part James–Stein estimator, and the James–Stein risk result [JS61] does not establish its risk. baux.calibrate separately fits corrections from validation pairs; coverage on adaptively collected optimization data requires its own justification.

Below, a PyTree domain combining logarithmic gain, periodic phase, simplex filter weights, and a categorical window drives a noisy 6-channel response concentrated near a rank-2 frame:

import math
import numpy as np
import baux

rng = np.random.default_rng(3)
space = {
    "gain": baux.Log(1e-3, 1.0),
    "phase": baux.Periodic(0.0, 2.0 * math.pi),
    "weights": baux.Simplex(4),
    "window": baux.categorical(["hann", "hamming", "blackman", "kaiser"]),
}
loadings = np.array([
    [1.0, 0.0],
    [0.8, 0.2],
    [0.2, 0.9],
    [-0.4, 0.7],
    [0.5, -0.5],
    [-0.3, -0.6],
])
frame = baux.Stiefel.from_factors(loadings)
target_w = np.array([0.45, 0.30, 0.15, 0.10])
win_loss = {"hann": 0.0, "hamming": 0.04, "blackman": 0.08, "kaiser": 0.01}


def spectral_channels(p):
    g_err = math.log10(p["gain"] / 0.05)
    ph_err = math.sin(0.5 * (p["phase"] - 1.2))
    w_err = float(np.sum((np.sqrt(p["weights"]) - np.sqrt(target_w)) ** 2))
    latent = np.array([-(g_err**2 + w_err + win_loss[p["window"]]), -(ph_err**2)])
    return loadings @ latent + 0.15 * rng.normal(size=6)


pipe = (
    baux.enn(k=8, geometry="conformal")
    | baux.stein(frame)
    | baux.ucb(beta=1.5)
    | baux.regions(count=3)
)
state = baux.init(space, pipe, key=baux.key(19))
for _ in range(10):
    state, batch = baux.ask(state, num_arms=3)
    y = np.vstack([spectral_channels(p) for p in batch.params])
    state, mu_shrunk = baux.tell(state, batch, y)

assert mu_shrunk.shape == (3, 6) and state.y_obs.shape == (30, 6)
