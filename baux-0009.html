Local Trust Regions & Functional State

1. Multi-Region Search & Asynchronous Evaluation

Over high-dimensional boxes, probability mass and epistemic uncertainty concentrate near boundaries, pulling global acquisition away from interior optima. baux.regions counters that boundary bias by running \(R\) local axis-aligned trust regions \(\{T_r(x_{0,r}, \ell _r, g_r)\}_{r=1}^R\) centered at regional incumbents \(x_{0,r}\) with side lengths \(\ell _r\) and restart generations \(g_r\) (Eriksson et al. [EPG+19], Daulton et al. [DEB+22]). Consecutive successes double \(\ell _r\) and stalls halve \(\ell _r\) until restart, while candidate pools perturb sparse coordinate subsets around \(x_{0,r}\); for vector targets (\(M \ge 2\)), each region scalarizes normalized outputs with simplex weights [DEB+22].

Incumbent sharing between those regions selects either regional isolation (sharing="origin_only") or adoption of any superior observation inside the Euclidean ball circumscribing \(T_r\) (sharing="ellipsoid_ball"). When workers return evaluations asynchronously, each proposed arm carries an AskId ticket \((r, g, a)\) tying it to region \(r\), generation \(g = g_r\), and slot \(a\). Out-of-order completions via baux.complete always record observations in \(\mathcal {D}\), but apply trust-region updates to \(T_r\) only when \(g = g_r\) so stale pre-restart workers cannot shrink or re-center a restarted region, while baux.cancel drops abandoned slots without altering \(\mathcal {D}\).

2. Deterministic Rollouts & Checkpointing

Every OptimizerState threads a splittable 128-bit PRNG key alongside observation history and regional trust-region records (Claessen & Pałka [CP13], Steele, Lea, & Flood [SLF14]). Sequential rollouts via baux.scan and pre-split parallel branches \(k \mapsto (k_1, \dots , k_B)\) via baux.pmap therefore produce deterministic trajectories independent of thread scheduling.

To resume interrupted studies identically, baux.freeze and baux.thaw serialize that complete solver snapshot into an authenticated binary record indexed by baux.digest. Restoring against any domain-compatible template \(s_0\) satisfies \(\mathrm {thaw}(s_0, \mathrm {freeze}(s)) = s\), guaranteeing identical subsequent proposals and parallel rollouts:

import numpy as np
import baux

bounds = np.tile([-3.0, 3.0], (8, 1))
weights = np.geomspace(1.0, 16.0, 8)


def anisotropic_loss(x):
    return -np.sum(weights * (x - 0.35) ** 2 + 0.1 * np.cos(3.0 * x), axis=1)


pipe = (
    baux.lhd(8)
    | baux.enn(k=6)
    | baux.thompson()
    | baux.regions(count=4, sharing="ellipsoid_ball")
)
s0 = baux.init(bounds, pipe, key=baux.key(101))
s_warm, b_init = baux.ask(s0, num_arms=8)
s_warm = baux.complete(s_warm, b_init.ids, anisotropic_loss(b_init.points))

s_live, b1 = baux.ask(s_warm, num_arms=2)
s_live, b2 = baux.ask(s_live, num_arms=2)
s_live = baux.complete(s_live, [b2.ids[0]], anisotropic_loss(b2.points[:1]))
s_live = baux.cancel(s_live, [b2.ids[1]])
s_live = baux.complete(s_live, b1.ids, anisotropic_loss(b1.points))

blob = baux.freeze(s_live)
restored_a = baux.thaw(s0, blob)
restored_b = baux.thaw(s0, baux.freeze(restored_a))
assert baux.freeze(restored_a) == blob
assert baux.digest(s_live) == baux.digest(restored_a) == baux.digest(restored_b)

rollouts_live = baux.pmap(
    s_live,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
rollouts_a = baux.pmap(
    restored_a,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
rollouts_b = baux.pmap(
    restored_b,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
assert rollouts_live == rollouts_a == rollouts_b and len(set(rollouts_live)) == 4
