Functional State & Asynchronous Portfolios

1. Pure State Transitions & Epoch-Stamped Regional Ledgers

Optimization state is an immutable tuple in the product space

\[ S \eqdef \mathcal {K} \times \mathcal {D} \times \prod _{r=1}^R T_r \times \mathrm {Spec}(\mathcal {M}), \]

joining a splittable 128-bit PRNG key \(k \in \mathcal {K}\) (Claessen & Pałka [CP13], Steele, Lea, & Flood [SLF14]), global observation history \(\mathcal {D}\), \(R\) concurrent local trust-region ledgers \(\{T_r(x_{0,r}, \ell _r, g_r)\}_{r=1}^R\) (Eriksson et al. [EPG+19], Daulton et al. [DEB+22]), and the compiled domain chart specification \(\mathrm {Spec}(\mathcal {M})\). Multi-objective portfolios (\(M \ge 2\)) draw per-region simplex weights to scalarize normalized objectives [DEB+22], while arm allocation across regions balances normalized incumbent value against completed plus in-flight evaluations.

Asynchronous evaluation decouples global surrogate updates from regional side-length adaptation via epoch-stamped tickets \(\mathrm {AskId} = (r, g, a)\), recording originating region \(r\), its generation epoch \(g = g_r\) at dispatch, and arm slot \(a\). Out-of-order completions via baux.complete always append observations to \(\mathcal {D}\), whereas trust-region expansion/contraction on \(T_r\) applies if and only if \(g = g_r\)—preventing delayed evaluations from a pre-restart epoch from perturbing a freshly re-centered basin—and baux.cancel releases in-flight slot reservations without altering \(\mathcal {D}\). Cross-region coordination is governed by incumbent adoption: sharing="origin_only" restricts \(x_{0,r}\) updates to region-\(r\) proposals, whereas sharing="ellipsoid_ball" adopts any superior global observation falling inside the Euclidean ball circumscribing \(T_r\)'s solver-coordinate box around \(x_{0,r}\), propagating local gains across overlapping basins while preserving distinct modes.

2. Splittable Rollouts & Canonical Snapshot Commutativity

Because appending observations alters neighbor sets and regional incumbents, baux.ask and baux.tell form an order-dependent Mealy transition system rather than commuting updates. Reproducibility instead rests on pure functional folding (baux.scan), pre-split parallel branch keys \(k \mapsto (k_1, \dots , k_B)\) (baux.pmap) that render parallel rollouts invariant to worker scheduling, and lossless binary checkpointing. For a template state \(s_0 \in S\) fixing \(\mathrm {Spec}(\mathcal {M})\) and any pure step transition \(\Phi _f : S \to S\), canonical serialization baux.freeze \(: S \to \mathcal {B}\) and deserialization baux.thaw \(: \mathcal {B} \to S\) commute with rollout execution \(\widehat {\Phi }_f \eqdef \mathrm {freeze} \circ \Phi _f \circ \mathrm {thaw}_{s_0}\):

\[ \begin {CD} S @>{\Phi _f}>> S \\ @V{\mathrm {freeze}}VV @AA{\mathrm {thaw}_{s_0}}A \\ \mathcal {B} @>>{\widehat {\Phi }_f}> \mathcal {B} \end {CD} \]

The example below dispatches overlapping regional batches, completes and cancels tickets out of order via batch.ids, verifies canonical baux.freeze/baux.thaw idempotence and baux.digest parity, and confirms bit-identical parallel baux.pmap rollout digests across restored snapshots:

import numpy as np
import baux

bounds = np.tile([-3.0, 3.0], (8, 1))
weights = np.geomspace(1.0, 16.0, 8)


def anisotropic_loss(x):
    return -np.sum(weights * (x - 0.35) ** 2 + 0.1 * np.cos(3.0 * x), axis=1)


pipe = (
    baux.lhd(8)
    | baux.enn(k=6)
    | baux.thompson()
    | baux.regions(count=4, sharing="ellipsoid_ball")
)
s0 = baux.init(bounds, pipe, key=baux.key(101))
s_warm, b_init = baux.ask(s0, num_arms=8)
s_warm = baux.complete(s_warm, b_init.ids, anisotropic_loss(b_init.points))

s_live, b1 = baux.ask(s_warm, num_arms=2)
s_live, b2 = baux.ask(s_live, num_arms=2)
s_live = baux.complete(s_live, [b2.ids[0]], anisotropic_loss(b2.points[:1]))
s_live = baux.cancel(s_live, [b2.ids[1]])
s_live = baux.complete(s_live, b1.ids, anisotropic_loss(b1.points))

blob = baux.freeze(s_live)
restored_a = baux.thaw(s0, blob)
restored_b = baux.thaw(s0, baux.freeze(restored_a))
assert baux.freeze(restored_a) == blob
assert baux.digest(restored_a) == baux.digest(restored_b)

rollouts_a = baux.pmap(
    restored_a,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
rollouts_b = baux.pmap(
    restored_b,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
assert rollouts_a == rollouts_b and len(set(rollouts_a)) == 4
