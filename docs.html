baux Documentation

Black-box Bayesian optimization in Python and Rust with trust-region search, Epistemic Nearest Neighbors (ENN) surrogates, and GPU acceleration.

1. Overview

baux provides a straightforward ask/tell optimization loop for bounded continuous search spaces. The core algorithms are implemented in Rust with optional GPU kernels (Apple Metal and NVIDIA CUDA) and first-class Python bindings.

  • Trust-Region Search (TuRBO): Local trust regions that adapt bounding box scale based on consecutive successes and failures.
  • Epistemic Nearest Neighbors (ENN): Non-parametric surrogate modeling that estimates both function values and spatial epistemic uncertainty through distance-weighted metric neighborhoods.
  • Hardware Acceleration: Metal and CUDA routines accelerate distance calculations, neighbor indexing, and candidate proposals when GPUs are present.
  • Ecosystem Integrations: Adapters for BoTorch, Ax, and Optuna.

4. Quickstart

A standard ask/tell loop minimizing a sphere function:

import numpy as np
from baux import create_optimizer, turbo_enn

# Search space: 2 dimensions in [-2.0, 2.0]
bounds = np.array([[-2.0, 2.0], [-2.0, 2.0]])

# Initialize optimizer with TuRBO trust-regions and ENN surrogate
opt = create_optimizer(
    bounds=bounds,
    config=turbo_enn(),
    rng=np.random.default_rng(42),
)

# Run optimization rounds
for iteration in range(20):
    # Ask for a batch of candidate points
    candidates = opt.ask(4)

    # Evaluate objective (baux maximizes rewards; negate for minimization)
    scores = -np.sum(candidates**2, axis=1)

    # Tell outcomes back to the optimizer
    opt.tell(candidates, scores)

print("Optimization finished.")

5. Python API Reference

create_optimizer

Factory function to build an optimizer instance:

from baux import create_optimizer, turbo_enn, turbo_one, turbo_zero
import numpy as np

bounds = np.array([[-1.0, 1.0], [-1.0, 1.0]])

# Choose configuration: turbo_enn(), turbo_one(), or turbo_zero()
opt = create_optimizer(
    bounds=bounds,
    config=turbo_enn(),
    rng=np.random.default_rng(0),
)

# Propose candidates:
candidates = opt.ask(4)  # returns ndarray of shape (4, 2)

# Record observations:
opt.tell(candidates, scores)

Trust-Region Configurations

Pre-configured search policies:

  • turbo_enn(): Trust-region optimization using an Epistemic Nearest Neighbors surrogate.
  • turbo_one(): Single trust region with Gaussian Process surrogate.
  • turbo_zero(): Baseline local trust region with no surrogate model.

Epistemic Nearest Neighbors (ENN)

Use the ENN model standalone for regression and uncertainty estimation:

from baux import ENN
from baux.enn.enn_params import ENNParams
from baux.index import NeighborIndex
import numpy as np

# Fit over observed points (train_x: NxD, train_y: Nx1)
model = ENN(train_x, train_y, index_driver=NeighborIndex.FLAT)

# Evaluate posterior distribution at query points
params = ENNParams(k_neighbors=8, epistemic_scale=1.0, aleatoric_scale=0.1)
post = model.posterior(query_x, params=params)

print("Mean:", post.mu)
print("Epistemic uncertainty:", post.se_epi)
print("Aleatoric noise:", post.se_ale)

# Draw non-parametric posterior sample trajectories
draws, indices = model.posterior_draw(query_x, params=params, function_seeds=[42])

BoTorch & Ax Interoperability

Wrap an ENN model inside a BoTorch-compatible Model:

import torch
import numpy as np
from baux import ENN
from baux.botorch import Model, Sampler
from baux.enn.enn_params import ENNParams

x = np.random.normal(size=(20, 3))
y = np.sin(x[:, :1])
model = Model(ENN(x, y), ENNParams(k_neighbors=4, epistemic_scale=1.0, aleatoric_scale=0.1))

# Query through the standard BoTorch posterior interface
test_x = torch.randn(5, 3, dtype=torch.double)
posterior = model.posterior(test_x)
print("Mean:", posterior.mean)
print("Variance:", posterior.variance)

Optuna Interoperability

Use baux as a custom sampler in Optuna:

import optuna
from baux import turbo_enn
from baux.optuna import Sampler
from optuna.distributions import FloatDistribution

search_space = {
    "x": FloatDistribution(-5.0, 5.0),
    "y": FloatDistribution(-5.0, 5.0),
}
sampler = Sampler(search_space, config=turbo_enn(), seed=42)

def objective(trial):
    x = trial.suggest_float("x", -5.0, 5.0)
    y = trial.suggest_float("y", -5.0, 5.0)
    return -(x**2 + y**2)

study = optuna.create_study(sampler=sampler, direction="maximize")
study.optimize(objective, n_trials=30)
print("Best parameters:", study.best_params)
