BAUX Software Documentation

High-performance black-box Bayesian optimization powered by resident GPU state, Epistemic Nearest Neighbors (ENN), and mathematically checked Lean 4 transition laws.

1. Overview & Philosophy

BAUX is a modern, production-grade Bayesian optimization framework designed for high-throughput simulation loops, complex scientific engineering (including fusion plasma control in TokaGym and 1D transport PDEs in Torax), and non-stationary black-box search spaces.

  • Resident GPU Execution: State transitions, trust-region scaling, and neighbor search stay entirely inside accelerator memory with zero host-to-device synchronization per evaluation round.
  • Dual-Surrogate Architecture: Combines local Gaussian Processes with global Epistemic Neural Networks (ENN) to capture both sharp local gradients and multimodal uncertainty.
  • Formally Checked Foundations: 189 formal Lean 4 modules prove compiler correspondence, IEEE-754 bit-exact reproducibility, and zero-sorry type signatures.

4. Python Quickstart

Standard ask/tell loop over continuous bounded parameters:

import baux
import numpy as np

# Synthetic non-convex objective (Ackley in 10 dimensions)
def objective(x):
    return -np.sum(x**2, axis=-1)

# Create TuRBO-1 optimizer on [0, 1]^10 with batch size 4
opt = baux.create_optimizer(dim=10, batch_size=4, max_evals=100)

for iteration in range(25):
    # Ask for candidate points
    trial = opt.ask()
    print(f"Iteration {iteration}: evaluating {len(trial.candidates)} candidates")

    # Evaluate your black-box simulation or physical experiment
    rewards = objective(trial.candidates)

    # Tell outcomes back to the optimizer
    opt.tell(trial.ask_id, rewards)

print("Optimization complete!")
print("Best candidate:", opt.best_x)
print("Best reward:", opt.best_y)

5. Python API Reference

baux.create_optimizer

Factory method initializing a production optimizer instance:

opt = baux.create_optimizer(
    dim=10,                      # Dimension of input domain [0, 1]^d
    batch_size=4,                # Number of candidates proposed per ask()
    max_evals=200,               # Maximum budget
    surrogate="enn",             # "enn" | "gp" | "hybrid"
    device="auto",               # "auto" | "metal" | "cuda" | "cpu"
)

Trust-Region (TuRBO-1 & TuRBO-m)

BAUX incorporates an exact native implementation of Trust-Region Bayesian Optimization with adaptive lengthscale shrinkage upon consecutive failures and expansion upon successful discoveries: 

from baux.turbo.config import OptimizerConfig

cfg = OptimizerConfig(
    length_min=0.5**7,
    length_max=1.6,
    success_tolerance=3,
    failure_tolerance=5,
)

Epistemic Neural Networks (ENN)

ENN surrogates decompose predictive variance into epistemic (model ignorance) and aleatoric (noise) components using randomized prior networks and ensemble heads: 

from baux.enn import ENN, ENNFitter

enn = ENN(input_dim=10, hidden_dim=64, num_heads=16)
fitter = ENNFitter(learning_rate=1e-3, epochs=20)
fitter.fit(enn, train_x, train_y)

# Sample posterior draw
draw = enn.posterior_draw(test_x)

BoTorch & Ax Platform Interop

Drop-in replacement for standard Gaussian Process models in existing BoTorch/Ax pipelines:

from baux.botorch import BauxModel
import torch

train_X = torch.rand(20, 5)
train_Y = torch.sin(train_X[:, 0:1])

model = BauxModel(train_X, train_Y)
posterior = model.posterior(torch.rand(10, 5))
print("Posterior mean:", posterior.mean)
print("Posterior variance:", posterior.variance)

Optuna Sampler Interop

import optuna
from baux.optuna import BauxSampler

def objective(trial):
    x = trial.suggest_float("x", -5.0, 5.0)
    y = trial.suggest_float("y", -5.0, 5.0)
    return -(x**2 + y**2)

study = optuna.create_study(sampler=BauxSampler(), direction="maximize")
study.optimize(objective, n_trials=50)
