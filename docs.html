1. Overview

baux is built for expensive, noisy, multi-modal optimization loops. Instead of relying solely on heavy global Gaussian processes that scale as O(N3), baux combines local trust-region bounding boxes with metric-weighted nearest neighbors:

  • Trust-Region Bayesian Optimization (TuRBO): Proposes candidate batches inside a local hypercube centered at the incumbent. Dynamically expands upon consecutive successes and contracts upon stagnation.
  • Epistemic Nearest Neighbors (ENN): Decomposes uncertainty into epistemic (sparsity of evaluations) and aleatoric (observation noise) components through calibrated k-nearest neighbor distance fields.
  • Resident GPU Execution: State updates, distance metrics, and candidate sampling run on-device (Apple Silicon Metal MPS or NVIDIA CUDA) with zero host synchronization per evaluation.

3. Quickstart (Ask / Tell Loop)

The core optimization flow is a clean ask(batch_size) and tell(candidates, scores) loop: 

import numpy as np
from baux import create_optimizer, turbo_enn

# Define parameter bounds: 2 continuous dimensions in [-2.0, 2.0]
bounds = np.array([[-2.0, 2.0], [-2.0, 2.0]])

# Create optimizer with TuRBO trust-region and ENN surrogate
opt = create_optimizer(
    bounds=bounds,
    config=turbo_enn(),
    rng=np.random.default_rng(42),
)

# Run optimization rounds
for iteration in range(20):
    # 1. Ask for a batch of candidate points
    candidates = opt.ask(4)

    # 2. Evaluate your objective function (baux maximizes rewards)
    scores = -np.sum(candidates**2, axis=1)

    # 3. Tell observations back to the optimizer
    opt.tell(candidates, scores)

print("Best observed candidate:", opt.best_x)
print("Best observed reward:", opt.best_y)

import optuna
from baux import turbo_enn
from baux.optuna import Sampler
from optuna.distributions import FloatDistribution

search_space = {
    "x": FloatDistribution(-5.0, 5.0),
    "y": FloatDistribution(-5.0, 5.0),
}
sampler = Sampler(search_space, config=turbo_enn(), seed=42)

def objective(trial):
    x = trial.suggest_float("x", -5.0, 5.0)
    y = trial.suggest_float("y", -5.0, 5.0)
    return -(x**2 + y**2)

study = optuna.create_study(sampler=sampler, direction="maximize")
study.optimize(objective, n_trials=30)
print("Best parameters:", study.best_params)

4. Trust-Region Mechanics (TuRBO)

TuRBO (Trust Region Bayesian Optimization) maintains a bounding hypercube of side length L centered at the best observed point (the incumbent):

  • Expansion: When consecutive candidate batches yield discoveries that improve on the incumbent, the trust region expands (L ← min(L × 1.5, Lmax)).
  • Contraction: When candidates stall across failure_tolerance consecutive batches, the trust region shrinks (L ← max(L × 0.5, Lmin)).
  • Restart: If L shrinks below length_min, the trust region resets with a new anchor point to escape local traps.

Pre-configured search policies:

  • turbo_enn(): Trust-region search using an Epistemic Nearest Neighbors surrogate.
  • turbo_one(): Single trust region with Gaussian Process surrogate.
  • turbo_zero(): Local trust-region search without a surrogate model.

5. Epistemic Nearest Neighbors (ENN)

ENN models function predictions by weighting observations by metric distance in the normalized input space:

  • post.mu: Empirical weighted mean prediction at query coordinates.
  • post.se_epi: Epistemic standard error, scaling with distance to the nearest evaluated points (large in unexplored space, small near observations).
  • post.se_ale: Aleatoric noise floor, reflecting evaluation variability.
