API Reference

import baux lazily loads functional state transitions, pipeline stages, parameter domain specifications, and standalone Epistemic Nearest Neighbor (ENN) surrogates. Across all entrypoints, flat input arrays x have shape (N, D) (float64) inside natural domain bounds [low, high], and objective arrays y (maximization convention) and optional observation variances y_var have shape (N,) for scalar targets or (N, M) (float64) for multi-output targets. Functional entrypoints (baux.init, baux.ask, baux.tell, baux.enn_init, baux.enn_append) take and return immutable state objects (OptimizerState, ENNState) whose array properties return read-only views (writeable=False), while Optimizer and ENN wrap the same solver in stateful classes.

2. Pipeline Stages

Validate domain bounds and configuration, initialize random state from rng, and construct an in-place stateful baux.Optimizer.

  • config (OptimizerConfig, keyword-only) — Configuration record specifying surrogate, trust region, and acquisition rules.
  • rng (np.random.Generator, keyword-only) — NumPy random generator providing the initial 63-bit seed.
Returns
Optimizer — Stateful optimization harness.
Example
import numpy as np
import baux

bounds = np.array([[-1.0, 1.0], [-2.0, 2.0]])
cfg = (baux.enn(k=5) | baux.ucb(beta=1.5))()
rng = np.random.default_rng(0)
opt = baux.create_optimizer(bounds=bounds, config=cfg, rng=rng)
x = opt.ask(num_arms=3)
y = np.sum(x**2, axis=-1, keepdims=True)
pred = opt.tell(x, y)
telem = opt.telemetry()

assert x.shape == (3, 2)
assert pred.shape == (3, 1)
assert isinstance(telem, baux.Telemetry)
