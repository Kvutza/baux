Instantiates an optimization state machine over a bounded continuous domain.

create_optimizer(
    bounds: np.ndarray,
    config: Optional[OptimizerConfig] = None,
    rng: Optional[np.random.Generator] = None,
) -> Optimizer
  • bounds: 2D array of shape (D, 2) defining lower and upper bounds [l_i, u_i] for each parameter dimension.
  • config: Search policy preset: turbo_enn(), turbo_one(), or turbo_zero().
  • rng: Seeded NumPy random generator for deterministic sampling reproducibility.

    Interface. Optimizer Methods

    • Kvutza
    • ask(batch_size=1) -> np.ndarray: Proposes a candidate trial matrix of shape (batch_size, D) bounded within the active trust region.
    • tell(candidates, scores) -> None: Updates trust-region state machine with observed evaluations under a maximization objective.
    • best_x -> np.ndarray: Coordinates of the incumbent parameter point.
    • best_y -> float: Best observed reward value.
