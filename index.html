Baux

baux searches for parameters using objective evaluations. You supply a domain and a function; the optimizer proposes parameters, receives their measured values, and uses those observations to choose its next proposals. Objectives may return a scalar or a vector, with optional observation variances. The Python API maximizes values, so a loss to minimize enters as its negative.

A search configuration specifies how to generate candidates, how to rank them, and how to update the search region. These choices can combine a surrogate with an acquisition rule, or select candidates without a surrogate. Multiple regions can explore different centers and share observations. The sections below explain the evaluation loop, the coordinates it searches, and the predictions it uses; the API reference gives the corresponding calls and shapes.

1. An Evaluation Loop

baux.init creates the search state. baux.ask returns a new state and a batch of proposed points; the objective evaluates those points outside the optimizer. baux.tell records the returned values. This example combines Epistemic Nearest Neighbors (ENN) with upper-confidence acquisition (UCB):

import numpy as np
import baux


def objective(x):
    return -np.sum((x - 0.4) ** 2, axis=1)


bounds = np.tile([-2.0, 2.0], (6, 1))
pipe = baux.enn(k=10) | baux.ucb(beta=2.0)

state = baux.init(bounds, pipe, key=baux.key(0))
for _ in range(15):
    state, batch = baux.ask(state, num_arms=4)
    state, _ = baux.tell(state, batch, objective(batch.points))

assert state.num_observations == 60
assert state.best_x.shape == (6,)

Here the six coordinates have box bounds and each point produces one value. The same loop can return structured parameters through batch.params and record several output channels per point. The example establishes the calling convention; it is not a comparison of optimization methods.

2. Local Trust Regions & Functional State

2.1. Multi-Region Search & Asynchronous Evaluation

A region keeps a center, a search length, and a record of recent improvements. Under the TuRBO controller, success and failure counts expand or contract the search length; a sufficiently small region restarts. TuRBO introduced multiple local models with global allocation of evaluations (Eriksson et al. [EPG+19]). In baux, baux.regions configures the regional search, while the pipeline chooses the surrogate and acquisition rule.

Candidate generation perturbs coordinates around a region's center. Incumbent sharing determines whether a result from another region may replace that center: origin_only restricts updates to the originating region, while ellipsoid_ball also admits better observations inside the region's circumscribing ball. This sharing decision is distinct from the choice of surrogate.

Asynchronous workers return results through baux.complete. Each AskId identifies a pending evaluation associated with a region and its generation. Restarting a region invalidates its old pending evaluations; foreign, completed, cancelled or invalidated IDs are rejected. baux.cancel retires unfinished evaluations without adding observations. Historical results can enter separately through baux.import_observations.

2.2. Deterministic Rollouts & Checkpointing

The functional API returns a new OptimizerState after each transition. Explicit PRNG keys let baux.scan run a fixed sequence and baux.pmap assign a derived key to each branch. Splittable generators are described by Claessen and Pałka [CP13] and Steele et al. [SLF14]. Replaying a search also requires the same objective results and transition order; a seed alone does not make arbitrary asynchronous completion orders equivalent.

baux.freeze serializes optimizer state with a BLAKE3 integrity tag. baux.thaw restores it against a compatible template. The checkpoint does not capture an external evaluator's random generator or worker state. The following example uses a deterministic objective and checks that the restored optimizer produces the same branch digests:

import numpy as np
import baux

bounds = np.tile([-3.0, 3.0], (8, 1))
weights = np.geomspace(1.0, 16.0, 8)


def anisotropic_loss(x):
    return -np.sum(weights * (x - 0.35) ** 2 + 0.1 * np.cos(3.0 * x), axis=1)


pipe = (
    baux.lhd(8)
    | baux.enn(k=6)
    | baux.thompson()
    | baux.regions(count=4, sharing="ellipsoid_ball")
)
s0 = baux.init(bounds, pipe, key=baux.key(101))
s_warm, b_init = baux.ask(s0, num_arms=8)
s_warm = baux.complete(s_warm, b_init.ids, anisotropic_loss(b_init.points))

s_live, b1 = baux.ask(s_warm, num_arms=2)
s_live, b2 = baux.ask(s_live, num_arms=2)
s_live = baux.complete(s_live, [b2.ids[0]], anisotropic_loss(b2.points[:1]))
s_live = baux.cancel(s_live, [b2.ids[1]])
s_live = baux.complete(s_live, b1.ids, anisotropic_loss(b1.points))

blob = baux.freeze(s_live)
restored_a = baux.thaw(s0, blob)
restored_b = baux.thaw(s0, baux.freeze(restored_a))
assert baux.freeze(restored_a) == blob
assert baux.digest(s_live) == baux.digest(restored_a) == baux.digest(restored_b)

rollouts_live = baux.pmap(
    s_live,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
rollouts_a = baux.pmap(
    restored_a,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
rollouts_b = baux.pmap(
    restored_b,
    baux.key(77),
    branches=4,
    branch_fn=lambda i, st, k: baux.digest(
        baux.scan(st, k, steps=4, eval_fn=anisotropic_loss, num_arms=2)[0]
    ),
)
assert rollouts_live == rollouts_a == rollouts_b and len(set(rollouts_live)) == 4

3. Structured Inputs & Multi-Output Shrinkage

3.1. Parameter Coordinate Maps

A structured domain tells the optimizer how to encode parameters as coordinates and decode proposals for evaluation. baux.init accepts nested dictionaries, tuples and dataclasses. For such a domain, batch.points contains solver coordinates and batch.params contains decoded parameters. Each leaf specifies its own map; the examples below show how that choice affects distance and valid proposals.

  • Log-scale intervals (baux.Log): On \([a, b] \subset \mathbb {R}_+\), \[ \psi (x) = \frac {\log x - \log a}{\log b - \log a} \in [0, 1], \qquad \rho (u) = a\left (\frac {b}{a}\right )^{\Pi _{[0,1]}(u)}, \] so uniform steps in \(u\) correspond to constant multiplicative ratios in \(x\).
  • Periodic intervals (baux.Periodic): On \(\lbrack a, b\rparen \) of period \(P = b - a\) with phase \(\phi (x) = \tfrac {2\pi (x - a)}{P}\), circle embedding and \(\operatorname {atan2}\) decoding, \[ \psi (x) = \left (\frac {1}{2} + \frac {\cos \phi (x)}{2\pi },\; \frac {1}{2} + \frac {\sin \phi (x)}{2\pi }\right ), \qquad d_{\mathcal {U}}\bigl (\psi (x), \psi (x')\bigr ) = \frac {1}{\pi }\left |\sin \left (\frac {\phi (x) - \phi (x')}{2}\right )\right |, \] avoid artificial jumps across the wrap boundary \(a \equiv b\).
  • Probability simplices (baux.Simplex): On \(\Delta ^{d-1}\), the square-root map onto the positive unit sphere and radial normalization, \[ \psi (p) = \bigl (\sqrt {p_1}, \dots , \sqrt {p_d}\bigr ) \in S_+^{d-1}, \qquad \rho (u) = \frac {\max (u, 0)^{\odot 2}}{\Vert \max (u, 0)\Vert _2^2}, \] give squared coordinate distance \(\sum _j(\sqrt {p_j}-\sqrt {q_j})^2\), equal to twice squared Hellinger distance under the convention \(H^2(p,q)=\tfrac 12\sum _j(\sqrt {p_j}-\sqrt {q_j})^2\). The decoder returns the uniform distribution when all clipped coordinates are zero.
  • Discrete sets (baux.categorical): Finite choices \(\{1, \dots , C\}\) map to equal-norm orthogonal or Rademacher codewords \(\psi (c) \in \mathbb {R}^{d_c}\) (Achlioptas [Ach03]), reducing nearest-codeword decoding to \(\rho (u) = \arg \max _c \langle u, \psi (c)\rangle \).

3.2. Linear Subspace Shrinkage

Vector observations may contain a component aligned with a known subspace and a residual outside it. baux.Stiefel.from_factors orthonormalizes a full-rank basis \(L\) to obtain \(V\). With \(P=VV^\top \), a contraction factor \(\alpha \in [0,1]\) preserves the projected component and reduces the residual:

\[ \hat {\theta }_\alpha = P y + \alpha (I_M - P)y. \]

To see the tradeoff, suppose \(y=\theta +\eta \in \mathbb {R}^M\) with zero-mean noise, a fixed subspace of rank \(1 \le r < M\), and a fixed \(\alpha \). Write \(v_\parallel =\mathbb {E}\Vert P\eta \Vert ^2\), \(v_\perp =\mathbb {E}\Vert (I-P)\eta \Vert ^2>0\), and \(b_\perp ^2=\Vert (I-P)\theta \Vert ^2\). Orthogonality gives mean squared error \(\mathcal {R}(\alpha )=v_\parallel +(1-\alpha )^2 b_\perp ^2+\alpha ^2 v_\perp \). Its minimizer is:

\[ \alpha ^* = \frac {b_\perp ^2}{b_\perp ^2 + v_\perp }, \qquad \mathcal {R}(\alpha ^*) = v_\parallel + \frac {v_\perp b_\perp ^2}{b_\perp ^2 + v_\perp } < v_\parallel + v_\perp = \mathcal {R}(1). \]

This is an oracle calculation: the off-subspace signal energy is unknown. baux.stein instead computes a contraction from the predicted residual energy and predicted variances. That fitted rule is not the positive-part James–Stein estimator, and the James–Stein risk result [JS61] does not establish its risk. baux.calibrate separately fits corrections from validation pairs; coverage on adaptively collected optimization data requires its own justification.

Below, a PyTree domain combining logarithmic gain, periodic phase, simplex filter weights, and a categorical window drives a noisy 6-channel response concentrated near a rank-2 frame:

import math
import numpy as np
import baux

rng = np.random.default_rng(3)
space = {
    "gain": baux.Log(1e-3, 1.0),
    "phase": baux.Periodic(0.0, 2.0 * math.pi),
    "weights": baux.Simplex(4),
    "window": baux.categorical(["hann", "hamming", "blackman", "kaiser"]),
}
loadings = np.array([
    [1.0, 0.0],
    [0.8, 0.2],
    [0.2, 0.9],
    [-0.4, 0.7],
    [0.5, -0.5],
    [-0.3, -0.6],
])
frame = baux.Stiefel.from_factors(loadings)
target_w = np.array([0.45, 0.30, 0.15, 0.10])
win_loss = {"hann": 0.0, "hamming": 0.04, "blackman": 0.08, "kaiser": 0.01}


def spectral_channels(p):
    g_err = math.log10(p["gain"] / 0.05)
    ph_err = math.sin(0.5 * (p["phase"] - 1.2))
    w_err = float(np.sum((np.sqrt(p["weights"]) - np.sqrt(target_w)) ** 2))
    latent = np.array([-(g_err**2 + w_err + win_loss[p["window"]]), -(ph_err**2)])
    return loadings @ latent + 0.15 * rng.normal(size=6)


pipe = (
    baux.enn(k=8, geometry="conformal")
    | baux.stein(frame)
    | baux.ucb(beta=1.5)
    | baux.regions(count=3)
)
state = baux.init(space, pipe, key=baux.key(19))
for _ in range(10):
    state, batch = baux.ask(state, num_arms=3)
    y = np.vstack([spectral_channels(p) for p in batch.params])
    state, mu_shrunk = baux.tell(state, batch, y)

assert mu_shrunk.shape == (3, 6) and state.y_obs.shape == (30, 6)

4. Neighborhood Surrogates

4.1. Inverse-Variance Prediction from \(K\) Nearest Neighbors

A surrogate estimates values at points that have not yet been evaluated. Epistemic Nearest Neighbors (ENN; Bafna et al. [BJS25]) forms that estimate from nearby observations. For scalar data \(\mathcal {D} = \{(x_m, y_m, s_m)\}_{m=1}^N\), let \(y_m = f(x_m) + s_m\varepsilon _m\), with independent standard normal \(\varepsilon _m\). ENN assigns each neighbor a measurement-noise term and a distance-dependent uncertainty term. Given dissimilarity \(\delta \), target variance \(\hat {\sigma }_y^2 > 0\), and positive scale parameters \(s_0^2,c_e\), these terms are:

\[ \mu (x \mid x_m) = y_m, \qquad \sigma _a^2(x \mid x_m) = \hat {\sigma }_y^2 s_0^2 + s_m^2, \qquad \sigma _e^2(x \mid x_m) = \hat {\sigma }_y^2 c_e\, \delta (x, x_m). \]

Select the \(K\) nearest observations, with index set \(N_K(x)=\{\pi _1(x),\ldots ,\pi _K(x)\}\), and give each inverse-variance weight \(w_i(x) = (\sigma _a^2(x \mid x_{\pi _i(x)}) + \sigma _e^2(x \mid x_{\pi _i(x)}))^{-1}\). ENN combines their values and uncertainty as follows [BJS25]:

\[ \mu (x) = \frac {\sum _{i=1}^K w_i(x)\, y_{\pi _i(x)}}{\sum _{i=1}^K w_i(x)}, \qquad \sigma _a^2(x) = \frac {\sum _{i=1}^K w_i(x)\, \sigma _a^2(x \mid x_{\pi _i(x)})}{\sum _{i=1}^K w_i(x)}, \qquad \sigma _e^2(x) = \frac {1}{\sum _{i=1}^K w_i(x)}, \]

The total predictive variance is \(\sigma ^2(x) = \sigma _e^2(x) + \sigma _a^2(x)\). A UCB rule uses the predicted value and uncertainty to rank candidates. ENN fits its scale parameters with a leave-one-out Gaussian pseudolikelihood; the paper also describes a noise-free variant that skips fitting and ranks candidates by non-domination in predicted value and epistemic uncertainty [BJS25]. For a fitting subsample \(S_P\) of size \(P\), the pseudolikelihood is:

\[ \widehat {\log \mathcal {L}}(\theta ) = -\frac {1}{2P} \sum _{n \in S_P} \left [\log \bigl (2\pi \sigma _{-n}^2(x_n; \theta )\bigr ) + \frac {\bigl (y_n - \mu _{-n}(x_n; \theta )\bigr )^2}{\sigma _{-n}^2(x_n; \theta )}\right ], \]

where \(\theta =(s_0^2,c_e)\), and \(\mu _{-n}\) and \(\sigma _{-n}^2\) omit observation \(n\) from its \(K\)-neighbor set.

4.2. Joint Draws Added by BAUX

The published ENN method does not provide the joint sampling required by Thompson acquisition (Bafna et al. [BJS25], §6). baux adds a shared-neighbor construction: attaching one independent standard normal variable \(z_{s,m,j} \stackrel {\text {i.i.d.}}{\sim } \mathcal {N}(0, 1)\) to every stored observation \(m \in \{1, \dots , N\}\) and output channel \(j\) couples candidate draws through overlapping neighborhoods without factoring a \(Q \times Q\) covariance matrix.

For a nonempty neighborhood and the default draws without observation noise, let \(\bar {w}_{i,j}(x) = w_{i,j}(x) / \sum _{r=1}^K w_{r,j}(x)\) denote normalized weights. Extend them by zero outside \(N_K(x)\), writing \(\tilde {w}_{m,j}(x)\), and set \(\Vert \bar {w}_j(x)\Vert _2 = \bigl (\sum _{i=1}^K \bar {w}_{i,j}^2(x)\bigr )^{1/2}\). Under the independent-normal model, normalization gives the marginal distribution:

\[ \tilde {f}_{s,j}(x) = \mu _j(x) + \frac {\sigma _{e,j}(x)}{\Vert \bar {w}_j(x)\Vert _2} \sum _{i=1}^K \bar {w}_{i,j}(x)\, z_{s,\pi _i(x),j} \sim \mathcal {N}\bigl (\mu _j(x),\, \sigma _{e,j}^2(x)\bigr ). \]

Under this idealized independent-normal construction, two queries share random variables where their neighbor sets overlap, \(S_K(x,x')=N_K(x)\cap N_K(x')\). Extending the normalized weights by zero outside the neighbor set gives:

\[ \operatorname {Cov}\bigl (\tilde {f}_{s,j}(x),\, \tilde {f}_{s,j}(x')\bigr ) = \frac {\sigma _{e,j}(x)\,\sigma _{e,j}(x')}{\Vert \bar {w}_j(x)\Vert _2\,\Vert \bar {w}_j(x')\Vert _2} \sum _{m \in S_K(x, x')} \tilde {w}_{m,j}(x)\,\tilde {w}_{m,j}(x') \ge 0. \]

4.3. Local-Scale Distances under Uneven Sampling

Neighbor selection depends on the distance supplied to ENN. Local scaling uses a point's neighbor radius to account for different sample spacings, as in Zelnik-Manor and Perona [ZP04]. Let \(d(x,x')=\Vert x-x'\Vert _2\) and let \(\sigma (x)>0\) denote a local neighbor radius. BAUX offers the following dissimilarities; choosing one changes the neighborhoods and the predictions.

  • Conformal scaling (Zelnik-Manor & Perona [ZP04]) divides squared Euclidean distance by the product of endpoint spacings: \[ \delta _c(x, x_m) = \frac {d^2(x, x_m)}{\sigma (x)\,\sigma (x_m)}. \]
  • Poincaré half-space distance (Beardon [Bea83], Cannon et al. [CFK+97], Nickel & Kiela [NK17]) associates each point with \((x, \sigma (x)) \in \mathcal {X} \times \mathbb {R}_+\) under \(ds^2 = (\Vert dx\Vert _2^2 + d\sigma ^2)/\sigma ^2\). Evaluating \(\cosh d_{\mathbb {H}} - 1\) adds a scale-difference penalty to conformal distance: \[ \delta _h(x, x_m) = \frac {d^2(x, x_m)}{2\,\sigma (x)\,\sigma (x_m)} + \frac {\bigl (\sigma (x) - \sigma (x_m)\bigr )^2}{2\,\sigma (x)\,\sigma (x_m)}. \] A large ratio between the endpoint scales increases the second term. This penalizes cross-scale matches; it does not guarantee that the selected neighbors belong to a particular basin.
  • Hybrid dissimilarity (wasserstein in the API) combines a rescaled position difference with a spacing difference: \[ \delta _w(x, x_m) = \frac {d^2(x, x_m)}{\sqrt {\sigma (x)\,\sigma (x_m)}} + \bigl (\sigma (x) - \sigma (x_m)\bigr )^2. \]

The wasserstein name denotes this implemented formula, not a claim that it is the Wasserstein distance between probability distributions. The example below checks neighbor membership, the variance decomposition, and sample correlation on one constructed dataset. Those assertions illustrate the API; they do not establish uncertainty calibration or an advantage on other objectives.

import numpy as np
import baux

rng = np.random.default_rng(7)
basin_x = 0.6 + 0.04 * rng.normal(size=(24, 6))
shell_x = rng.uniform(-1.5, 1.5, size=(24, 6))
train_x = np.vstack([basin_x, shell_x])

signal = np.exp(-1.5 * np.sum((train_x - 0.6) ** 2, axis=1, keepdims=True))
train_yvar = np.vstack([np.full((24, 1), 5e-4), np.full((24, 1), 5e-2)])
train_y = signal + np.sqrt(train_yvar) * rng.normal(size=(48, 1))

k_fit, k_draw = baux.split(baux.key(11), 2)
enn_state = baux.with_geometry(
    baux.enn_init(train_x, train_y, train_yvar, scale_x=True),
    "hyperbolic",
    local_k=4,
)
params = baux.enn_fit(enn_state, k=8, infer_aleatoric=False, key=k_fit)

queries = np.vstack([
    np.full((1, 6), 0.600),
    np.full((1, 6), 0.601),
    np.full((1, 6), 2.400),
])
post = baux.enn_posterior(
    enn_state, queries, params, flags=baux.enn.PosteriorFlags(observation_noise=True)
)
draws, idx = baux.enn_sample(enn_state, queries, params, key=k_draw, num_draws=64)

corr_basin = float(np.corrcoef(draws[0, 0], draws[1, 0])[0, 1])
assert np.all(idx[0] < 24)
assert post.se_epi[0, 0] < post.se_epi[2, 0]
assert np.allclose(post.se**2, post.se_epi**2 + post.se_ale**2)
assert corr_basin > 0.8

5. What the Control Studies Test

The control studies evaluate neural policies through simulated rollouts. The TCV study compares ten-region search without a surrogate against one-region ENN search. Because both the region count and the surrogate change, this comparison measures the complete configurations; it does not isolate the effect of ENN. The four sharing configurations in the surrogate-free TCV study produced identical recorded optimization trajectories.

The TCV results support a comparison of those configurations on that simulator and budget. The simulation page gives the methods, measured differences and uncertainty, then describes the TORAX evaluator and synthetic test functions.
